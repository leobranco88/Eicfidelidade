1. HEADER
───────────────────────────────────────
→ Logo EIC centralizado (símbolo C + ponto laranja)
→ Fundo com gradiente: #FF5C00 → #6B3FA0 → #070738
→ Nome do responsável em branco, Playfair Display
   ex: "Olá, Maria Silva!"
→ Subtítulo pequeno em branco:
   "Programa Indique um Amigo · 1º Semestre 2026"

2. CARD DE NÍVEL ATUAL
───────────────────────────────────────
→ Card branco centralizado
→ Badge do nível em destaque (ver especificações abaixo)
→ Nome do nível em Playfair Display grande
→ Mensagem motivacional específica do nível

3. MÉTRICAS — 3 CARDS HORIZONTAIS
───────────────────────────────────────
→ Card 1: Total de indicações
   ícone pessoas, fundo laranja #FF5C00
→ Card 2: Matriculados
   ícone check, fundo verde
→ Card 3: Benefício atual
   ícone presente, fundo amarelo #F5A800

4. BARRA DE PROGRESSO
(apenas nos níveis Bronze, Prata e Ouro)
───────────────────────────────────────
→ Card branco
→ Ícone roxo de conquista
→ Título: "Faltam X matriculados para o nível [próximo]"
→ Barra de progresso roxa #6B3FA0
→ Pontinhos embaixo: Bronze · Prata · Ouro · Ambassador
→ No Ambassador: este card some e aparece o card de saldo

5. CARD DE SALDO
(apenas no nível Ambassador)
───────────────────────────────────────
→ Card branco com borda sutil roxa
→ Título: "Seu saldo"
→ Valor em destaque: ex "R$ 150"
   Playfair Display grande, laranja #FF5C00
→ Subtítulo: "A cada nova matrícula confirmada,
               você acumula R$50"
→ Barra de progresso roxa mostrando
   progresso até R$350
→ Texto: "Faltam R$200 para resgatar
           o material didático"
→ Quando atingir R$350:
   Barra fica amarela #F5A800, completa
   Aparece botão laranja: "Resgatar material didático"

Estados da barra de saldo:
R$50  → 14%  · R$100 → 28% · R$150 → 43%
R$200 → 57%  · R$250 → 71% · R$300 → 86%
R$350 → 100% → botão de resgate aparece

6. LISTA DE INDICADOS
───────────────────────────────────────
→ Título "Suas Indicações" Playfair Display
→ Card por indicado:
   - Nome do indicado
   - Data da indicação
   - Badge de status:
     · Aguardando contato → cinza
     · Em avaliação       → amarelo #F5A800
     · Matriculado        → verde
→ Estado vazio:
   ilustração + "Você ainda não fez indicações"

7. BOTÃO DE AÇÃO FIXO
───────────────────────────────────────
→ Botão laranja #FF5C00 largura total
→ Ícone UserPlus (Lucide)
→ Texto: "Indicar um Amigo"
→ Sempre visível em todos os níveis

8. CARD DO CERTIFICADO
(aparece nos níveis Ouro e Ambassador)
───────────────────────────────────────
→ Card gradiente suave laranja → roxo
→ Ícone de medalha amarelo centralizado
→ Título: "Seu Certificado Ambassador está pronto!"
→ Subtítulo: "Baixe, imprima e compartilhe."
→ Botão branco: "Ver Certificado"

9. RODAPÉ
───────────────────────────────────────

→ eicschool.com.br
→ Texto pequeno cinza:
   "Este link é exclusivo para você."
