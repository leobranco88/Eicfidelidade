ESTRUTURA DA PÁGINA (de cima para baixo)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. HEADER
───────────────────────────────────────
→ Logo EIC centralizado
→ Fundo com gradiente: laranja #FF5C00 
  → roxo #6B3FA0 → azul #070738
→ Nome do responsável em branco
  ex: "Olá, Maria Silva!"
→ Subtítulo pequeno: "Programa Indique um Amigo · 1º Semestre 2026"

2. CARD DE NÍVEL ATUAL
───────────────────────────────────────
→ Card branco com destaque
→ Badge do nível atual com ícone:
  - Beginner  → ícone de semente, roxo claro
  - Fluent    → ícone de chama, roxo médio
  - Ambassador → ícone de estrela, amarelo #F5A800
→ Nome do nível em Playfair Display grande
→ Frase motivacional embaixo:
  - Beginner:   "Você deu o primeiro passo!"
  - Fluent:     "Você está quase lá!"
  - Ambassador: "Você é um Embaixador EIC!"

3. MÉTRICAS — 3 CARDS HORIZONTAIS
───────────────────────────────────────
→ Card 1: Total de indicações (ícone pessoas, laranja)
→ Card 2: Matriculados (ícone check, verde)
→ Card 3: Benefício atual (ícone presente, amarelo)
  ex: "5% desconto" / "10% desconto" / "1 mês grátis"

4. BARRA DE PROGRESSO
───────────────────────────────────────
→ Card branco
→ Título: "Faltam X matriculados para o nível [próximo]"
→ Ícone roxo de conquista ao lado do título
→ Barra de progresso roxa #6B3FA0
→ Pontinhos embaixo mostrando etapas (1, 2, 3+)
→ Labels embaixo de cada ponto:
  "Beginner" · "Fluent" · "Ambassador"

5. LISTA DE INDICADOS
───────────────────────────────────────
→ Título "Suas Indicações" em Playfair Display
→ Lista de cards, um por indicado:
  - Nome do indicado
  - Data da indicação
  - Status com badge colorido:
    · Aguardando contato → cinza
    · Em avaliação       → amarelo
    · Matriculado        → verde
→ Se não houver indicações: 
  ilustração vazia + texto "Você ainda não fez indicações"

6. BOTÃO DE AÇÃO
───────────────────────────────────────
→ Botão laranja #FF5C00 largura total
→ Texto: "Indicar um Amigo"
→ Ícone de pessoa com + (Lucide: UserPlus)
→ Ao clicar: abre o formulário de indicação
  (mesma página de indicação já existente)

7. CARD DO CERTIFICADO (só aparece no nível Ambassador)
───────────────────────────────────────
→ Card com gradiente suave laranja → roxo
→ Ícone de medalha amarelo grande centralizado
→ Título: "Seu Certificado Ambassador está pronto!"
→ Subtítulo: "Baixe, imprima e compartilhe."
→ Botão branco: "Ver Certificado"

8. RODAPÉ
───────────────────────────────────────
→ Logo EIC pequeno centralizado
→ eicschool.com.br
→ Texto: "Este link é exclusivo para você. 
           Não compartilhe com outras pessoas."
